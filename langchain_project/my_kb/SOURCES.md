# Sources and Provenance

All documents in this knowledge base were authored specifically for this project, synthesizing architectural principles and detection metrics from the following academic and industrial publications:

1. **01_hpc_telemetry.md**: Synthesized from research on microarchitectural side-channel telemetry and hardware performance counters for hardware-assisted malware detection (e.g., Intel PT and PMU-based cryptographic loop detection).
2. **02_api_heuristics.md**: Derived from Windows API documentation and MITRE ATT&CK techniques: T1083 (File and Directory Discovery) and T1486 (Data Encrypted for Impact).
3. **03_decoy_traps.md**: Based on Windows Kernel File System Minifilter Driver design specifications and Shannon entropy heuristics for real-time cryptographic write detection.
4. **04_incident_mitigation.md**: Adapted from NIST SP 800-61 Rev. 2 (Computer Security Incident Handling Guide) containment workflows and live endpoint memory forensics methodologies.
