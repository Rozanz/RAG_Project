
# Sources

The security alert scenarios in `my_alerts.json` are fictional examples based on common cybersecurity monitoring activities. No production logs or employer data were used.

## Technical References

1. MITRE ATT&CK Framework
   https://attack.mitre.org/
   Reference for common adversary behaviors, including credential access, privilege escalation, and defense evasion.

2. Microsoft Windows Security Auditing
   https://learn.microsoft.com/en-us/windows/security/threat-protection/auditing/advanced-security-auditing-faq
   Reference for Windows security events and auditing concepts.

3. AWS CloudTrail User Guide
   https://docs.aws.amazon.com/awscloudtrail/latest/userguide/cloudtrail-user-guide.html
   Reference for cloud API activity and audit logging.
